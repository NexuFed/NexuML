class SuperDataset(meta_data_list: dict[str, NexuDataset], label_names: list[str] | None = None, merge_labels: dict[str, dict] | None = None, **kwargs)

Bases: NexuDataset

Merges multiple datasets (keyed by name) into one dataset.

Adds a “dataset” column to the merged DataFrame to track origin. Supports label merging and dataset subdivision for federated/multi-client scenarios.

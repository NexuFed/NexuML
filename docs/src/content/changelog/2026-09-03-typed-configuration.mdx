Reusable components are now explicit Pydantic definitions rather than loosely
typed parameter bags. Scenarios construct definitions in Python; persisted YAML
restores them through stable registry identities. Runtime objects are materialized
through build contexts.

The framework and reusable base library ship as separate distributions. Portable
model packages carry dependency metadata and checkpoint provenance. Ray execution,
S3 WebDataset export, and TensorShard window loading extend the existing training
and data lifecycle.

This release replaces legacy selector dictionaries and parameter bags. Read the
linked release notes before migrating existing scenarios.

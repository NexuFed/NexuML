---
title: Install NexuML
description: Install the framework and base library, with optional integrations when needed.
---

**Goal:** a working CLI and built-in examples. You need Python and `uv` (or another
package installer), not a framework checkout or GPU.

## Recommended installation

```bash
uv venv
source .venv/bin/activate
uv pip install "nexuml[library]"
```

On Windows, activate `.venv\Scripts\activate` with your shell's activation script.
This installs `nexuml` (framework/CLI/runtime) and `nexuml-library` (reusable components
and registered scenarios). Verify in the selected environment:

```bash
nexuml --help
nexuml registry list scenarios
nexuml backend list
```

Look for `synthetic-linear-ae-reconstruction`, then [run one CPU epoch](/start/first-run/).

## Core-only installation

```bash
uv pip install nexuml
```

Use this if your project supplies all components. The core package intentionally
has no built-in `nexuml_library` scenarios.

## Optional integrations

Install only what you use: `tracking`, `tuning`, `export`, `ray`, `kubernetes`,
`s3`, or `api`. Extras can be combined, for example:

```bash
uv pip install "nexuml[tracking,tuning]"
```

`nexuml[all]` includes normal core integrations and the base library, but not
development tooling or DALI. The library has separate extras such as
`nexuml-library[audio]`, `[data]`, `[pretrained]`, and `[eval]`.

## Container image

Choose an **explicit tag** from [GHCR](https://github.com/NexuFed/NexuML/pkgs/container/nexuml).
Images are Linux AMD64, include CUDA tooling and both packages, and are larger
than a normal install; Docker Hub is not mirrored.

```bash
read -r -p "GHCR tag: " NEXUML_IMAGE_TAG
test -n "$NEXUML_IMAGE_TAG" && docker run --rm -it --gpus all "ghcr.io/nexufed/nexuml:$NEXUML_IMAGE_TAG"
```

Release tags use `<nexuml-version>-cuda<cuda-version>`; `edge-cuda` and
`sha-<short-sha>-cuda<cuda-version>` are development tags. GPU execution needs
a matching NVIDIA driver and [Container Toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html).
Omit `--gpus all` for CPU use; mount directories if outputs must survive `--rm`.

## CUDA and PyTorch

The default install resolves PyTorch from the public index. Install an appropriate
PyTorch CUDA build first if you need a particular version.

## NVIDIA DALI

On a compatible platform, install and check DALI separately:

```bash
uv pip install "nexuml[dali]" --index https://pypi.nvidia.com
python -c "import nvidia.dali"
```

`nexuml backend list data-loader` lists definitions, not dependency/driver health.
See [data loading](/how-to/data-loading/).

## Environment roots

```bash
export NEXUML_DATA_ROOT=/path/to/datasets
export NEXUML_LOGS_ROOT=/path/to/logs
```

These optional prefixes do not define one universal output tree. See
[environment resolution](/reference/environment/) or [contributor setup](/development/install/).

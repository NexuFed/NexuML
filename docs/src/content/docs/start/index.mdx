title: Start here
description: Choose a small first CPU run, from the CLI or Studio.
---

Both paths run the same synthetic reconstruction experiment for **one CPU epoch**.
Neither needs a repository checkout, GPU, or dataset download.

- **Terminal:** [Install NexuML](/start/install/), then [complete the first run](/start/first-run/).
- **Browser:** [Install Studio](/studio/) and select **Try an example**.

Afterward, [create your own scenario](/how-to/run-scenarios/) or build a library
through the [external tutorials](/tutorials/). [CIFAR ResNet](/start/cifar-resnet/)
is an optional next example requiring a download and extra dependencies.

---
title: Start here
description: Install NexuML, complete one small CPU experiment, and choose a next task.
---

You do not need a framework checkout, GPU, or a tour of every API to start.

1. [Install NexuML](/start/install/) with its reusable base library.
2. [Complete your first run](/start/first-run/): discover a recipe, resolve its configuration,
   build the model, and train for one epoch on locally generated data.
3. [Build your own library through the tutorials](/tutorials/) or go straight to
   [create/run scenarios](/how-to/run-scenarios/).

[Studio](/studio/) offers the same synthetic first run in a browser. The
[optional CIFAR ResNet example](/start/cifar-resnet/) adds a real dataset download
and tracking dependencies after the small default works.

When a question comes up, use [task guides](/how-to/), the
[architecture explanation](/explanation/architecture/), or [reference](/reference/).
They are not prerequisites to completing the first run.

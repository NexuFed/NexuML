Normal users should [install the packages](/start/install/), not clone the framework.
For contributors:

- [Development installation and workflow](/development/install/): source environment,
  Python tests/coverage/static checks, Studio, skills, and PR conventions.
- [Documentation contribution and publication](/development/documentation/): isolated docs
  tools, MDX, checks, preview, and archive-safe deployment.
- [Release procedure](/development/release/): exact-commit artifacts, protected registry
  publication, and institute-runner trust boundaries.

Choose the smallest relevant check; tests with GPU/data/optional prerequisites are not
certified by a successful static documentation build.

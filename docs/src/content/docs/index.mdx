NexuML is a Python/PyTorch framework for composing reusable data, model, loss,
and evaluation components into reproducible experiments. A typed scenario describes
the experiment; explicit TensorDict keys connect its blocks; Lightning runs it.

## Start here

1. [Install NexuML and the base library](/start/install/).
2. [Run a synthetic autoencoder for one CPU epoch](/start/first-run/)—no dataset download or GPU.
3. [Create and run your own scenario](/how-to/run-scenarios/) or learn through the [external tutorials](/tutorials/).

Prefer a browser? [NexuML Studio](/studio/) runs the same installed Python runtime.

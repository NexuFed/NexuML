title: NexuML
description: Compose reusable machine learning components into reproducible experiments.
---

NexuML composes reusable Python/PyTorch data, model, loss, and evaluation
components into reproducible experiments. A typed scenario defines the experiment,
TensorDict keys connect its blocks, and Lightning runs it.

**New here?** [Choose your first run](/start/): complete a synthetic CPU experiment
from the terminal or [Studio](/studio/), without a GPU or dataset download.

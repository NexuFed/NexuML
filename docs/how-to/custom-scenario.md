# Custom scenario walkthrough

The complete learn-by-building walkthrough has moved to the separate [NexuML Tutorials](../tutorials.md). Keeping a second full tutorial here caused examples to drift from the framework and duplicated the same scenario/library concepts.

Use the framework guides as focused references instead:

- [Define a scenario](define-scenario.md) — write a `ScenarioSpec` recipe;
- [Run scenarios](run-scenarios.md) — registered/YAML/trusted-file execution paths;
- [Build a custom library](custom-library.md) — package reusable components;
- [Add a custom layer](custom-layer.md), [data source](custom-data-source.md), or [evaluation algorithm](custom-eval-algorithm.md) — extension contracts.

For a progressive project where every component is tutorial-owned, start with [Tutorials](../tutorials.md).

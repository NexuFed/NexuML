nexuml.execution.definitions

Core execution definitions; importing settings never imports cluster runtimes.

Classes

NameDescription
ConfigHandoffExplicit shared filesystem or S3 destination for one frozen worker config.
KubernetesExecutionInfrastructure-owned template and named training resource bindings.
KubernetesJobExecutionSubmit one Kubernetes training pod.
LocalExecutionRun the existing NexuML session in the current process.
PyTorchJobExecutionSubmit the served Kubeflow Training Operator PyTorchJob resource.
RayClusterExecutionRay placement configuration; training semantics stay in TrainingSpec.
RayClusterTargetAn explicit existing Ray cluster and its native runtime environment.
RayJobExecutionSubmit a KubeRay RayJob; its template owns the cluster and cleanup policy.

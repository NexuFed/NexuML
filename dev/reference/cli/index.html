Export a dataset view from a scenario or config

Arguments and options for nexuml export-dataset
NameType / defaultMeaning
scenario_namestrScenario name
--config, -cpathConfig YAML path
--output, -ostrdefault: "exported_dataset"Path or s3:// URI
--backendstrdefault: "numpy"Dataset export backend
--splitrepeatablestrSplit to export. Repeat the option to export multiple splits.

--samples-per-shardintdefault: 256Samples per WebDataset tar shard

--s3-profilestrOptional AWS credential profile name

nexuml tune

Run Optuna hyperparameter search on a scenario

Arguments and options for nexuml tune
NameType / defaultMeaning
scenario_namestrScenario name
--scenario-filepathTrusted Python file exposing scenario() -> ScenarioSpec
--artifact-dirpathOptional directory for scenario-file provenance snapshots
--n-trialsintNumber of Optuna trials
--metricstrMetric to optimise (default: tuning_spec.metric_key or val/loss)
--directionstrOptuna direction: minimize or maximize (default: from tuning_spec)
--storagestrOptuna storage path
--prune, --no-prunebooleanEnable Optuna pruning
--override, -OrepeatablestrOverride a scenario field: key.path=value. Repeatable.
--helpbooleanShow this message and exit.
